## 1.1.5

### Improved
- **CLEAR RACK** now asks before it clears the rack.
- The web editor's "show on the S32" for a Step Seq step now opens that step's settings with the setting you clicked selected.

### Fixed
- Step Seq changes you make on the S32 (holding a step to edit it, the step's settings list, a pad toggle and **RANDOMIZE**) now count as unsaved changes, so switching projects asks before they are lost.
- After you save, the web editor now shows the project as saved.
